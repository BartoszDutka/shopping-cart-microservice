# Shopping Cart Microservice

A layered shopping cart service integrated with product management and notification services.

## Features

- Separate API, application, domain and infrastructure layers
- cart workflows
- service integration
- container orchestration

## Technology stack

C#, .NET, MongoDB, RabbitMQ, Docker Compose.

## Getting started

Review the projects under `ZTP3` and supporting services under `ZTP1` and `ZTP2`. Configure fresh local development credentials and review the Compose configuration before starting services. Do not commit secrets.
